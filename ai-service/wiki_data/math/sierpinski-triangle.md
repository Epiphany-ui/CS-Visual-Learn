# 谢尔宾斯基三角形

## 一、定义

谢尔宾斯基三角形（Sierpinski triangle）是一种具有严格自相似性的分形几何结构，由波兰数学家瓦茨瓦夫·谢尔宾斯基于1915年提出。它可以被描述为：从一个等边三角形出发，反复移除中心“倒立”的小三角形（其顶点位于原三角形各边中点）后得到的极限图形。其数学定义常用**迭代函数系统**（Iterated Function System, IFS）给出：设三个仿射变换 \( f_1, f_2, f_3 \) 分别将整个三角形缩小至其三个角上的子三角形，则谢尔宾斯基三角形是满足 \( S = f_1(S) \cup f_2(S) \cup f_3(S) \) 的唯一紧集。从计算角度看，递归生成伪代码如下：

```
function sierpinski(points, depth):
    if depth == 0:
        draw triangle(points)
    else:
        let a, b, c = points
        let m1 = midpoint(a, b)
        let m2 = midpoint(b, c)
        let m3 = midpoint(c, a)
        sierpinski([a, m1, m3], depth-1)
        sierpinski([b, m1, m2], depth-1)
        sierpinski([c, m2, m3], depth-1)
```

## 二、核心原理

1. **自相似性**：图形局部与整体在几何形状上完全相同，只是比例不同。任意一个子三角形放大2倍后与原图形重合。
2. **迭代构造**：初始三角形（阶数0）经过一次移除操作得到阶数1的图形（包含3个小三角形），每迭代一次图形数量乘以3，边长减半。重复无限次即得极限图形。
3. **豪斯多夫维数**：谢尔宾斯基三角形的维数为 \( \log_2 3 \approx 1.585 \)，介于1维（曲线）与2维（平面）之间，体现了分形“分数维”的本质。
4. **测度性质**：其面积为 0（因为每次移除掉1/4面积，剩余面积按 \( (3/4)^n \) 衰减），但点集为不可数无穷，且具有非零的 \( \log_2 3 \) 维测度。
5. **混沌游戏**：另一种生成方式：随机选取初始点，每次随机选取三个顶点之一，向该顶点移动一半，反复迭代后点集无限逼近谢尔宾斯基三角形（以概率1收敛）。

## 三、过程/示例

以阶数 \( n=2 \) 的递归构造为例，初始三角形顶点坐标为 A(0,0), B(1,0), C(0.5, √3/2)。为简化，使用等边三角形边长1。

- **步骤 0**：绘制完整的三角形（阶数0）。
- **步骤 1**：计算三边中点：
  - m1 = (0.5, 0) —— AB中点
  - m2 = (0.75, √3/4) —— BC中点
  - m3 = (0.25, √3/4) —— CA中点  
  移除三角形 (m1, m2, m3)，剩余三个小三角形：
   - T1: A, m1, m3
   - T2: B, m1, m2
   - T3: C, m2, m3
- **步骤 2**：针对每个小三角形重复步骤1。以 T1 为例：
   - T1顶点 A(0,0), m1(0.5,0), m3(0.25, √3/4)
   - 其三边中点：
     - p1 = (0.25, 0) —— A与m1中点
     - p2 = (0.375, √3/8) —— m1与m3中点
     - p3 = (0.125, √3/8) —— m3与A中点
   - 移除中心倒三角形 (p1, p2, p3)，得到三个更小的三角形。对T2、T3同理。
   
最终图形包含 3² = 9 个边长为 1/4 的实心小三角形，中间有3个大小不等的空洞（1个大的，3个稍小的）。继续迭代将产生更多层次的自相似空洞。

## 四、复杂度/性质分析

- **递归生成时间复杂度**：每深度增加1，子问题数变为3倍，每个子问题耗时常数。设递归深度为 \( n \)，则总调用次数 = \( 3^n \)，时间复杂度 \( O(3^n) \)。若直接绘制所有点（如像素填充），复杂度与点数成正比，深度10-12即可获得足够精细图形。
- **空间复杂度**：若仅递归不存储中间结果，调用栈深度为 \( n \)，空间复杂度 \( O(n) \)。若采用显式点集存储，所需点数随深度指数增长（ \( O(3^n) \) ），空间复杂度亦为指数。
- **混沌游戏复杂度**：每步仅需随机选择和几何计算，生成 \( N \) 点的时间复杂度 \( O(N) \)，空间 \( O(1) \)（仅保留当前点）。收敛速度：点集以概率1在理论谢尔宾斯基三角形内处处稠密，但需要大量点才能显式逼近细节（通常 \( N \geq 10^5 \) 效果较好）。
- **稳定性**：数值计算中，浮点误差会影响中点计算，导致点漂移。以双精度浮点数迭代15次以上可能产生明显偏差，但在计算机图形学中通常限制迭代深度在10以内。
- **收敛性**：递归构造在极限意义下收敛到谢尔宾斯基三角形，其Hausdorff距离随深度递减（与 \( 2^{-n} \) 同阶）。混沌游戏以概率1收敛，但收敛速度较慢——点越密集，需要的点越多。

## 五、常见误区

1. **混淆谢尔宾斯基三角形与谢尔宾斯基地毯**：前者基于三角形，每次移除中心倒三角形；后者基于正方形，每次移除中心小正方形（九宫格中心）。两者维数不同（三角形≈1.585，地毯≈1.892），构造规则也截然不同。
2. **误认为面积为零意味着图形不存在或没有点**：面积为零并不等于点集为空。谢尔宾斯基三角形包含不可数无穷多个点，只是这些点的二维勒贝格测度为0。类似康托尔集，它是完备的疏朗集。
3. **认为递归深度必须无限大才有意义**：在实际绘图和工程应用中，有限深度（如5~8阶）已经能清晰展示自相似特征。即便只迭代几次，图形也具有分形的核心视觉结构，且数学上可定义递归极限。
4. **混淆豪斯多夫维数与拓扑维数**：谢尔宾斯基三角形的拓扑维数为1（因为它可以被分解为曲线般的连通分支），但豪斯多夫维数约为1.585。这个差异是分形区别于常规几何体的关键特征。初学者常误以为维数就是整数维或图上“看得见的维度”。
5. **混沌游戏误以为初始点需落在三角形内部**：实际上从任意点出发（包括三角形外部），经过足够多次迭代后点集仍会收敛到谢尔宾斯基三角形。但若初始点在图形上（如顶点），则后续点始终在三角形内部。常见误区是认为初始位置必须严格随机。
