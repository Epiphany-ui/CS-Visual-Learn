# 欧拉公式

## 一、定义

欧拉公式（Euler's formula）是复变函数论中连接复指数函数与三角函数的核心恒等式，其标准形式为：

\[
e^{i\theta} = \cos\theta + i\sin\theta, \quad \theta \in \mathbb{R}
\]

其中 \(e\) 是自然对数的底，\(i\) 是虚数单位（\(i^2 = -1\)）。该公式将实数指数函数推广到纯虚指数，并统一描述了复数在单位圆上的旋转。当 \(\theta = \pi\) 时，得到著名的欧拉恒等式：

\[
e^{i\pi} + 1 = 0
\]

将数学中五个最重要的常数（\(0,1,\pi,e,i\)）融为一体。

---

## 二、核心原理

1. **几何直观**：在复平面上，\(e^{i\theta}\) 表示模长为1、辐角为 \(\theta\) 的复数，对应的点恰好在单位圆上。\(\cos\theta\) 与 \(\sin\theta\) 分别给出该点的实部与虚部坐标。

2. **级数展开的一致性**：分别将 \(e^{i\theta}\)、\(\cos\theta\)、\(\sin\theta\) 展开为泰勒级数，代入 \(i\) 的幂次周期性（\(i^2=-1, i^3=-i, i^4=1\)），可严格证明等式成立。

3. **指数加法性质的继承**：\(e^{i(\alpha+\beta)} = e^{i\alpha} e^{i\beta}\) 等价于三角恒等式 \(\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta\)，\(\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta\)。这表明复指数乘法与角度加法完全对应。

4. **解析延拓**：欧拉公式可自然推广到任意复数 \(z = x+iy\)，得到 \(e^z = e^x(\cos y + i\sin y)\)，从而定义复指数函数的完整图像。

5. **欧拉公式的逆用**：利用该公式可将任意复数 \(a+bi\) 表达为极坐标形式 \(re^{i\theta}\)，为复数的乘幂、开方和旋转运算提供极大便利。

## 三、过程/示例

取具体角度 \(\theta = \frac{\pi}{3}\)（60°），演示欧拉公式的逐步验证：

**步骤1**：计算三角函数值  
\[
\cos\frac{\pi}{3} = \frac{1}{2}, \quad \sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}
\]  
所以 \(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3} = \frac{1}{2} + i\frac{\sqrt{3}}{2}\)。

**步骤2**：用泰勒级数近似计算 \(e^{i\pi/3}\)（取前5项）  
\[
e^{i\theta} = \sum_{n=0}^{\infty} \frac{(i\theta)^n}{n!} = 1 + i\theta - \frac{\theta^2}{2!} - i\frac{\theta^3}{3!} + \frac{\theta^4}{4!} + i\frac{\theta^5}{5!} - \cdots
\]  
代入 \(\theta=\pi/3 \approx 1.0472\)，逐项：
- \(n=0\): \(1\)
- \(n=1\): \(i \times 1.0472 \approx 1.0472i\)
- \(n=2\): \(-\frac{1.0472^2}{2} = -0.5483\)
- \(n=3\): \(-i\frac{1.0472^3}{6} \approx -i0.1914\)
- \(n=4\): \(\frac{1.0472^4}{24} \approx 0.0500\)
- \(n=5\): \(+i\frac{1.0472^5}{120} \approx i0.0087\)

**步骤3**：合并实部与虚部  
实部：\(1 - 0.5483 + 0.0500 = 0.5017\)  
虚部：\(1.0472 - 0.1914 + 0.0087 = 0.8645\)  
即近似值为 \(0.5017 + 0.8645i\)。

**步骤4**：与 \(\frac{1}{2} + i\frac{\sqrt{3}}{2} \approx 0.5 + 0.8660i\) 比较，误差极小。随着项数增加，两者严格相等。

## 四、复杂度/性质分析

作为数学恒等式，欧拉公式本身没有算法复杂度。但在计算领域应用时，需关注以下性质：

- **收敛性**：由泰勒级数定义的复指数在全复平面绝对收敛，收敛半径为无穷大，任意截断误差可控。
- **数值精度**：直接使用 \(\cos\theta + i\sin\theta\) 计算是精确的（除浮点舍入外）；若用级数逼近，项数需求随 \(|\theta|\) 增大而增加，可利用周期性 \(e^{i(\theta+2\pi)} = e^{i\theta}\) 将自变量归约到 \([0,2\pi)\)，提高效率。
- **空间复杂度**：存储一个复数需两个浮点数，即 \(O(1)\)。
- **稳定性**：在快速傅里叶变换（FFT）中，旋转因子 \(e^{-2\pi i k/N}\) 的计算常利用递推（如旋转因子乘积）或预先查表，避免反复求三角函数，算法复杂度为 \(O(N\log N)\)，数值稳定。
- **解析性质**：欧拉公式定义的函数是整函数（全纯），满足柯西-黎曼方程，具有周期 \(2\pi\)，是量子力学、信号处理中周期现象建模的基础。

## 五、常见误区

1. **混淆虚指数与实指数**：误认为 \(e^{i\theta}\) 是实数，如将 \(e^{i\pi} = -1\) 视为实数的负值而忽略其复指数本质。实际上 \(e^{i\theta}\) 是模为1的复数（单位圆上点），仅在 \(\theta = k\pi\) 时为实数。

2. **与图论中的欧拉公式混淆**：图论中 \(V - E + F = 2\) 描述平面图的顶点、边、面关系，与复指数公式截然不同。需根据上下文区分“欧拉公式”指代对象。

3. **忽视辐角主值范围**：将任意复数写成 \(re^{i\theta}\) 时，\(\theta\) 一般取主值 \((-\pi, \pi]\)。直接使用反三角函数计算辐角可能导致多值性或符号错误。

4. **错误推广到矩阵指数**：虽然矩阵指数有类似定义 \(e^{A} = I + A + \frac{A^2}{2!} + \cdots\)，但欧拉公式在矩阵中仅当 \(A\) 是斜对称矩阵（如 \(i\) 乘以某个实矩阵）时成立，一般情况不满足 \(e^{A+B} = e^A e^B\)。

5. **认为欧拉公式仅适用于纯虚数指数**：该公式可推广到一般复数 \(z=x+iy\)，得到 \(e^z = e^x(\cos y + i\sin y)\)，此完整形式在求解常微分方程、电路分析中更为常用。
